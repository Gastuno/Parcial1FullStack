Instalación: 1. Ejecutar Npm Install dentro de las carpetas "fsp1front" y "fsp1back"
2. Crear archivo ".env" dentro de la carpeta "fsp1back" tal que:

TMDB_API_KEY= (tu llave de api de TMDB)
TMDB_TOKEN= (tu token de TMDB)
PORT=3001

Ejecucíon: Para ejecutar el backend - "Npm start" dentro de la carpeta "fsp1back"
Para ejecutar el frontend - "Npm run dev" dentro de la carpeta "fsp1front"
